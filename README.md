## Featured Projects

### Smart Logistics Platform

Microservice-based logistics platform built with Java 21, Spring Boot and Spring Cloud.

The system consists of multiple services responsible for authentication, shipment management, shipment tracking and notifications. Spring Cloud Gateway provides a central API entry point, while Apache Kafka is used for event-driven communication between application components.

The platform includes an Angular frontend, PostgreSQL persistence, Docker Compose environment, CI with GitHub Actions and deployment to AWS EC2.

**Main features:**

- Microservice architecture
- API Gateway
- JWT authentication and authorization
- Shipment management
- Courier assignment
- Shipment tracking and history
- Event-driven communication with Apache Kafka
- Notification service
- PostgreSQL persistence
- Docker Compose
- GitHub Actions CI
- AWS EC2 deployment
- Swagger / OpenAPI documentation

**Tech:** `Java 21` `Spring Boot` `Spring Cloud Gateway` `Spring Security` `JWT` `PostgreSQL` `Apache Kafka` `Angular` `TypeScript` `Docker` `GitHub Actions` `AWS EC2`

[View Smart Logistics Platform](https://github.com/KarolDry/smart-logistics-platform)

### EventFlow Ticket Platform

Full-stack platform for event management, reservations and electronic ticket generation.

The backend was developed with Java 21 and Spring Boot, while the frontend was created using React. The application implements JWT authentication and role-based authorization.

Users can browse events, create and cancel reservations and display electronic tickets with QR codes. Administrators have a dedicated interface for managing events.

The backend uses PostgreSQL for persistence, Apache Kafka for event communication and Docker Compose for running the application infrastructure.

**Main features:**

- User registration and login
- JWT authentication
- Role-based authorization
- USER and ADMIN interfaces
- Event management
- Event reservations
- Reservation cancellation
- Electronic ticket generation
- QR code generation
- PostgreSQL database
- Apache Kafka integration
- Docker Compose
- Swagger / OpenAPI documentation

**Tech:** `Java 21` `Spring Boot` `Spring Security` `Spring Data JPA` `JWT` `PostgreSQL` `Apache Kafka` `Docker` `React` `Vite` `TailwindCSS`

[Backend Repository](https://github.com/KarolDry/eventflow-ticket-api)

[Frontend Repository](https://github.com/KarolDry/eventflow-ticket-frontend)

### LocaTeam Mobile

Mobile application for real-time location sharing and communication between members of private groups.

The application was developed using React Native and Expo with Firebase services responsible for authentication and real-time data synchronization.

Users can create private groups, invite other users, share their GPS location, communicate using group chat and send SOS alerts.

**Main features:**

- User authentication
- Private groups
- Group invitations
- Real-time GPS location sharing
- Interactive map
- Group chat
- SOS alerts
- SOS reactions
- Push notifications
- Real-time data synchronization

**Tech:** `React Native` `Expo` `JavaScript` `Firebase Authentication` `Cloud Firestore` `OpenStreetMap` `GPS` `Expo Notifications`

[View LocaTeam Mobile](https://github.com/KarolDry/locateam-mobile)
